Licence, sources and attribution

As far as the compilation is ours — the selection, reconciliation, ids, confidence scoring and structure — the catalogue is released under CC BY-NC 4.0: free to use, copy and redistribute, with attribution, for non-commercial purposes. The code that builds it is MIT.

The sources control their own fields. Every value the pipeline stores is a claim with its source, source URL and licence; each published value is resolved from those claims with a confidence and a basis, and a disagreement between sources is recorded, not averaged away. The published file does not carry that provenance per field: a downloader cannot tell which source a given date or ISBN came from, so the whole file is treated as non-commercial, CC BY-NC 4.0 plus the strictest terms of any source in it. BnF (Etalab Open Licence) and DNB (CC0) permit any use; Wikipedia contributes facts only, never prose; openBD is purpose-limited to book promotion and Open Library's terms are non-commercial. Google Books, MangaDex and Rakuten Books forbid database-building and are not used. The verified record of each source's terms is docs/legal-position.md; the data licence in full is LICENSE-DATA.md.
