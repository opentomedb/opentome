OpenTome

A multi-market volume catalogue for manga, light novels, manhwa and webtoons.

Per-volume metadata across Japanese, English, French and German release lines, with day-precision release dates, ISBNs and chapter-to-volume composition — published as one SQLite file that any library tool can read.

What it is, and is not

  • In: every volume of every line — release date, ISBN and page count where a source carries them — under a stable id (tome_id, never reused, never re-keyed), across markets, so one work's Japanese, English and French volumes line up. English lines carry the AniList id where one can be placed.
  • Not in: cover art. The file holds no images; some volumes carry a cover_url pointing at the source's own copy.
  • Not in: anything from the Grand Comics Database. The catalogue is built from Wikipedia facts, openBD, Open Library and BnF; DNB (CC0, the German primary source) is not yet wired in; AniList ids are looked up for the English lines. The pipeline records the source and licence of every value it takes.
